# Helm chart for UniFi Network Application - Project Deprecated

> [!CAUTION]
> **This repository is no longer actively maintained.**
>
> Due to changes by Ubiquiti that make running the UniFi Network Application within Kubernetes increasingly difficult, I have migrated my own instance to a dedicated Debian-based virtual machine running [UniFi OS Server](https://www.ui.com/download/releases/unifi-os-server). Because of this shift in my setup, I can no longer maintain or update this Helm chart fork.
>
> If you are looking for alternatives, consider looking into running a UniFi OS Server on a dedicated VM or exploring other community-maintained deployment options.
